## 能做什么

- PS逐层重建：位图生成／可选真实物体提取与PS合成，拒绝带背景裁片拼贴和隐藏文字冒充成果；文字形状按实际字形选择方法，原生重建须验证字形与内部间距，外框对齐不代表外观一致。像素替代须明确不可编辑。按需SeedVR2素材超分、透明/深浅底真实PS渲染检查、红色问题标注。原生PSD保留混合、变形与样式。使用和边界见[PS重建说明](docs/PHOTOSHOP_REBUILD.md)。

- 独立精细抠图：顶部“抠图”直接使用本地 BiRefNet HR-matting / Lucida v7，输出保持原画幅的透明图片新节点。设置独立保存，不消耗 Codex 额度，不触发分层、重建或矢量化。
- 图片 / 分层 PSD / 视频超分：顶部“超分”使用本地 SeedVR2 7B 标准版 INT8，支持2倍/4倍。PSD保留图层、位置和透明度；视频连续帧处理、保留时间戳和音轨，完成后生成关联新节点，可播放并导出MP4。需要另装约8.84GB模型与NVIDIA CUDA；不消耗Codex额度。视频单段2GB/10分钟以内、8位SDR，详见[超分说明](docs/UPSCALE.md)。

- 多图画布，图片可拖动、框选、多选、删除、撤销；结果生成新节点并连接来源节点。
- 四种 PSD 流程：BiRefNet HR 精细预览 + Codex 重建、Lucida v7 精细预览 + Codex 重建、本地粗抠预览 + Codex 重建、Codex 框规划 + Codex 重建。Codex 预分层只理解图片并给出带名称的虚线框，不抠图、不生图；所有模式都支持手动新建图层、命名和拖框，确认后才真实重建。精细流程直接读取干净输入，不串联粗蒙版；粗抠/精细抠图只有预览清晰度不同，重建时只提供原图与结构化标注，不传抠图图片或蒙版，不保留抠图像素。
- 三个本地模型分别设置参数，每项说明用途及调大/调小的影响；保存后作为当前画布后续任务和新画布的默认设置。
- 箭头、圈选、框选、涂抹和文字标注支持样式设置，文字可放在图片外；意见通过图片局部坐标提交。
- 预分层可拖动虚线边框调整每层设计画幅。超过150万像素会提示并计算预算内尺寸；极狭长透明层可增加生成留白，最终按参考点等比定位。设计框与实际素材边界分别记录，越框弱透明像素保留，避免反复缩小主体。支持逐层暂存和原件追溯。
- 总图意见与图层意见分别保存，标注以可点击的小标签排列。
- 四个矢量入口：Vectorizer.com、Recraft 官方 API、Vectorizer.AI 官方 API、302.AI 转接。
- PSD、SVG、PNG 导出，PSD / SVG 导入；Adobe 交接成功后可取得真实 AI 文件。
- 当前节点是修改基准，最初原图仅作辅助参考；不会自动重做上下游节点。
- “显示原图”开关用于对比，不改变任务输入或导出；亮暗主题与可拖动面板。


- 重建按层检查并最多追加两次针对性纠正，选择最好的一版；仍明显漂移则以红色自动标注和图层意见记录，继续其他层。结果节点可集中修正，整节点修改自动跳过保留层。所有预分层模式只显示当前选中图层的画幅框。

普通v4另提供显式黑底/白底双RGB解混实验，避免把固有黑墨亮度当覆盖；当前为工程候选，真实一致性尚未验证，PS不支持。普通v4也保留显式的已知中灰底前景解混实验：分别生成RGB外观与灰阶matte，再固定恢复前景颜色和透明度。带底色的中间图不能作为正式层，旧任务不迁移；PS尚不支持该实验。数值相容不代表原海报一致性通过，使用边界见[重建实验](docs/RECONSTRUCTION_EXPERIMENTS.md)。

## 运行与费用

Codex 加载插件连接时自动启动本地画布服务，不强行打开侧栏，也不加载抠图权重。首次使用仍在目标对话说“打开分层画布”。关闭标签不停止服务；所有已关联 Codex 宿主退出后，等待本地任务、导出及发送请求完成，再经过约15–20秒空闲缓冲停止。再次加载插件会复用原端口、凭证和本地历史；按需打开工具仍可作为启动备用。

本地画布、保存、导入导出以及本地粗抠、精细抠图不消耗 Codex 推理额度。需要 Codex 识别、生成重建、操作网页或操作 Adobe 时，会消耗相应额度；可用工具取决于你的 Codex 版本和账户。API 费用由所选服务商另外收取，按层转换可能发生多次请求。

画布按钮通过官方 Codex App Tools 的对话发送工具提交到绑定对话。需要桌面宿主实际提供该能力；发送成功不代表图像生成完成。插件不使用另一个 OpenAI API 账号替代当前 Codex 对话。

**已移除 PSD 方案1和本地 SuperSVG / AdaVec 矢量化入口及退役实验代码。** 本地抠图模型为 U2NetP、BiRefNet HR-matting 和 Lucida v7；可另装 SeedVR2 7B INT8 图片/PSD/视频超分，VOSR方案已移除。当前完整需求见 [需求文档](docs/REQUIREMENTS.md)。

复杂艺术字、特殊混合模式、透明细节和背景重建需要人工验收；不能保证任意图片都能无损恢复成原始设计文件。免费网站验证可能中断自动化；不要绕过验证。详见教程与限制文档。
