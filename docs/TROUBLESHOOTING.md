# 常见问题

| 现象 | 先怎么做 |
|---|---|
| 找不到插件工具 | 确认安装注册完成并重新加载插件；新对话检查工具清单，不要把构建成功当成安装成功 |
| 画布打不开/拒绝访问 | 从目标 Codex 对话重新说“打开分层画布”，使用返回的新链接；不要自己拼 taskId 或复制别人的访问令牌 |
| 请求发送失败 | 展开原因。确认官方 Codex App Tools、桌面宿主连接和当前真实对话绑定可用；重新打开画布刷新连接。不要伪造接单状态 |
| 已发送但未完成 | 当前对话可能忙。发送不代表生成完成；看对话是否实际领取了该 jobId，不要反复提交 |
| 执行中但没有新节点 | 让 Codex检查该任务的输出文件、回传及完成状态；下载成功但未回传也不算完成 |
| Vectorizer.com 弹验证 | 由用户完成验证后继续；不要绕过验证码。自动脚本失败可取消后选择 Codex 操作网页，旧失败任务不会自动变成新模式 |
| API 401/403/余额不足 | 检查选中服务商、该服务商的独立凭据和 API 余额；网页订阅不一定含 API |
| 模型未安装 | 方案2运行本地模型安装脚本，或选方案3。模型下载失败看来源和摘要校验，不关闭校验 |
| Adobe 部分成功 | MCP 与 Windows 脚本是不同通道。展开详情区分哪一项失败，实际复杂编辑仍需验证 |
| 显示原图不可用 | 先选一张图；等原图信息读取完成。缺少来源链时不能保证找到最初原图 |
| 标注突然不见 | 取消选择、多选、框选和原图对比会隐藏标注。回到结果并只选一张图片查看 |
| 保存冲突 | 停止继续编辑并保留输入内容，让 Codex检查并发版本；不要直接用旧文档覆盖服务器 |

## 给 Codex 的排查顺序

1. 读取具体失败消息与当前 taskId / jobId，不领取其他历史请求。
2. 区分服务存活、鉴权、对话发送、生成执行、下载、回传、前端显示。
3. 使用只读检查先找问题；当前请求取消/完成后不能重复执行。
4. 如需重启服务，先确认无运行任务且画布已保存，核对进程身份。保留所有 `data/` 和原始素材。
5. 解释已经验证到哪一步，不能用“节点已创建”代替“文件内容正确”。

## 报告问题

请提供 Windows / Codex 版本、选择的方案或服务商、操作步骤、预期和实际结果。可以附打码的截图与简短报错。不要公开 `data/service.json`、密钥、带 token 的链接、私人图片或完整对话。为复现准备一张自己有权公开的非敏感图片更有效。
