# 图片、分层 PSD 与视频超分

当前只使用 **SeedVR2 7B 标准版 INT8 ConvRot**。VOSR入口、推理代码及专用下载清单已移除；读取旧画布时自动迁移到SeedVR2，保留倍率和随机种子，清除退役参数。旧的结果文件和历史任务记录不改写；旧模型缓存不被当作当前依赖，也不自动删除用户已有文件。

## 使用

导入图片、PSD或视频，选中当前节点，点击顶部“超分”。完成后出现与来源相连的新节点，不自动处理上下游，不覆盖源文件。本地运行不消耗Codex额度。

图片与PSD：2倍或4倍。正式分层节点逐层处理位图，同步缩放坐标、画幅和标注，保留隐藏层、图层顺序和文字信息。可编辑文字不进入生成模型，字号、文本框和常用描边/阴影随倍率调整。透明度独立用Lanczos缩放后合回模型RGB；不是AI重建透明度。完全透明区域先延展邻近前景颜色以减少黑边。特殊PSD结构（独立/矢量蒙版、智能对象、特殊混合、剪贴、调整层、变形/路径文字等）会明确报错，不静默合并或丢弃。预分层使用干净输入；矢量节点超分输出位图。

视频：导入MP4、MOV、MKV、WebM或AVI，点击节点标题旁“播放”预览。原节点使用轻量预览文件，超分始终读取完整原视频；结果节点播放正式MP4。结果可导出MP4（H.264 + AAC）；原节点可下载原文件。进度显示已处理帧数，支持取消；失败、取消或删除源节点均不创建成功结果。视频节点暂不提供图片分层、抠图、矢量化、图像标注和Adobe交接。

视频按连续帧联合推理，前后时间段的重叠部分按同一时间戳融合；不是逐帧调用图片生成。不补帧、不改变播放速度，检查实际帧数、时间戳、时长、音轨数和输出尺寸。保留所有音轨内容及时间关系，音频重新编码为AAC，不承诺音频字节不变。支持可变帧率和90度倍数的旋转信息。

当前视频范围：单文件2GB以内、单段10分钟以内、最高120fps、8位不透明SDR、单视频轨、方形像素。HDR/PQ/HLG、高位深、透明视频、非方形像素或无效时间戳明确拒绝，避免悄悄变色或变形。单帧输出最多4000万像素、单边16384像素；此上限不保证显卡一定有足够显存。视频任务最多6小时，图片20分钟。长视频耗时、磁盘和显存应先用短片测试。

## 安装

让Codex执行 `powershell -ExecutionPolicy Bypass -File scripts/setup-seedvr2.ps1`。旧名称setup-upscale.ps1转发到此脚本，不再安装VOSR。需要Windows、Python 3.10–3.12 x64、NVIDIA CUDA及兼容驱动。

只下载标准7B INT8 ConvRot约8.33GB和一份FP16 VAE约0.50GB，不下载3B、Sharp或其他精度。依赖优先清华镜像，模型优先ModelScope；不可用或校验失败回退官方来源。固定版本和SHA-256见 `python/seedvr2-models.json`。运行推理不联网下载。视频编解码随Python依赖安装PyAV及imageio-ffmpeg，无需用户另配系统FFmpeg。

使用固定ComfyUI推理核心作为库，不启动ComfyUI服务器或UI，不加载用户自定义节点，也不读取用户ComfyUI路径。基础插件安装不会强制下载超分权重。需要预留源视频、预览、处理中间文件和输出空间。

## 参数

设置 → 图片 / 视频超分。每项有悬停说明，保存后用于当前画布后续任务与新画布；不改变运行中的任务。

| 参数 | 默认 | 作用与增减影响 |
|---|---|---|
| 倍率 | 2倍 | 宽高各乘2；4倍时像素16倍，更耗资源，不保证更忠实 |
| 颜色保持 | Lab | 匹配原图色彩；小波校正低频，整体匹配调整均值/对比度，关闭保留模型色彩 |
| 结果混合比例 | 100% | 降低可缓和假纹理，也减弱细节；0%为源图插值放大，不是去噪强度 |
| 编解码分块 | 512 | 输出像素边长；增大显存增加、块数减少，减小更省显存 |
| 编解码重叠 | 128 | 增大重复计算更多、可缓和接缝；最大为块边长1/4 |
| 显存模式 | 标准 | 省显存更积极卸载，可能更慢；不改变倍率或权重 |
| 随机种子 | 42 | 固定便于比较，数值更大不代表更好 |
| 视频连续帧数 | 9 | 可选5/9/17；增大时间上下文和显存需求，减小减少显存但分段增多 |
| 视频重叠帧 | 5 | 可选1/5/9且小于连续帧数；增大可缓和段间差异但重复计算更多 |
| 视频编码CRF | 18 | 16质量高/文件大，23文件小/压缩损失增加；不改变模型推理 |

固定Euler/simple/1步/CFG1/denoise1，主模型使用自身窗口注意力。图片显存不足有限重试更小编解码块；视频对相同连续帧组使用省显存设置重试，不悄悄退化为逐帧。仍不足会提示改为5帧或降低倍率。处理尺寸与时间段边界、细纹、文字、标志和人脸仍需视觉检查；成功回传不等于无损恢复。

## 验证边界

2026-10-01：本机RTX3090，17帧带音轨短片160×96→320×192，真实9帧/重叠5帧推理约12.44秒，PyTorch峰值已分配9.21GB。帧数、时间戳、时长、音轨数检查通过；这是小样本，不代表高清长片耗时或零闪烁。CPU媒体回归覆盖可变帧率、旋转、延迟音轨、尾段帧数和各种分段边界。图片/分层PSD回归保留坐标、负位置、透明度、隐藏层和可编辑文字，未承诺任意PSD与Photoshop原生逐效果一致。
