# 当前需求与验收边界

更新：2026-09-20。供设计师、维护者和接手的 Codex 使用，以最新确认需求为准。本文记录必须保持的行为，不代表所有外部服务已经实测成功。安装见 [INSTALL](INSTALL.md)，操作见 [USER_GUIDE](USER_GUIDE.md)，接口约定见 [CONTRACT](CONTRACT.md)。

## 平台、画布与保存

- **R01 平台与任务绑定**：仅支持 Windows。插件在 Codex 右侧打开，一个真实对话绑定一个独立画布。同一画布支持多张导入图片及 PSD，分别编辑；不另设插件聊天界面，不另开推理对话冒充当前额度。
- **R02 历史与数据保护**：重启后按相同 taskId 恢复同一文档、历史与视图；服务未启动和数据不存在要区分。素材、设置、历史、已确认结果和用户未提交代码不得被清理或重置。
- **R03 节点交互**：图片可拖动、单选、框选、多选、删除；删除不连带删除上下游。支持撤销。移动节点时，所属标注一起移动而图片局部坐标不变。
- **R04 操作范围与结果**：一次分层、修改、矢量化只处理提交时冻结的当前节点及指定图层。正式结果产生新的来源关联节点；保留原节点，不自动执行祖先或后代任务。来源连线保持现有 9px 粗细。
- **R05 布局**：紧凑统一图标与文字、明暗主题、可拖动尺寸的图层栏/意见栏/输入区，画布占主要空间。保留单一“显示原图”对比开关；切换对比不改变操作和导出的当前结果。

## PSD 分层与重建

导入图片不自动分层。先点击预分层，在对象规划框或本地透明预览、图层顺序、可见性和标注中调整，再确认正式生成。任何预分层模式均不调用生图工具。

| ID / 设置 | 预分层预览 | 确认后的真实分层 | 费用边界 |
|---|---|---|---|
| **R06 / 方案2** | U2NetP 本地粗抠 | 当前 Codex 重建每层、补全遮挡和背景 | 本地推理不消耗 Codex 额度；识别/生成消耗当前额度 |
| **R07 / 方案3** | 当前 Codex 理解干净图片，只提交名称、归属、虚线框与顺序，不抠图、不生图 | 当前 Codex 重建每层、补全遮挡和背景 | 规划消耗理解额度，确认后才消耗生图额度 |
| **R08 / BiRefNet HR-matting** | 从干净输入直接精抠，不先套粗抠蒙版 | 与方案2相同的 Codex 重建流程 | 本地推理免费；识别/生成使用当前额度 |
| **R09 / Lucida v7** | 从干净输入直接精抠，不先套粗抠蒙版 | 与方案2相同的 Codex 重建流程 | 同上 |

- **R10 预览不是最终像素**：所有粗抠、精抠和生成预览仅用于分层、对象归属、位置、顺序及意见标注。精抠只让预览清晰，不能成为更高权重的像素依据。重建包不得将预览图/蒙版作为生图参考，不复用、拼回预览像素；预览的 keep 标记也不代表像素获准保留。
- **R11 一致性与参考**：最初导入的干净原图是未要求修改部分的视觉参考；当前节点及已确认修改是工作基准，本次明确要求优先。保持身份、形状、构图、比例、位置、材质、光影、透明效果、字形等。只读追溯原图，不继承上游待办；原图缺失需明确告知。已确认正确的最终图层可保留，不重新生成。
- **R12 图层画幅**：预分层时可拖虚线框边缘/角点调整独立画幅，也可移动和重置；可撤销、保存和恢复。改变画幅不拉伸图中物体。任务冻结每层的 x/y/宽高；按每层画幅生成后放回整图，不默认每层生成整张大图。
- **R12a 新建规划层**：所有预分层模式均可新增无像素图层、命名、改框、排序、隐藏、删除、标注并填写意见；支持撤销和保存恢复。不调用模型，不用原图矩形截图冒充透明抠图。框内对象靠名称和标注明确；无图片文件的层也必须参加确认后的真实重建。未重建层不能当最终 PSD/矢量结果；历史预览不自动迁移或删除。
- **R13 合并与尺寸**：合并图层必须列出 sourceLayerIds，使用相应冻结画幅的并集；迁移图层意见与标注归属。最终画幅独立于生成分辨率。请求预算155万像素，超出只提示不阻止；实际返回宽高重算等比倍率，允许缩小或放大。相对宽高比误差≤1%可适配，>1%拒绝；完整透明画幅计入像素，不按主体自动裁边。保存原始文件与实际尺寸、裁切及补边偏移；显式裁切仅允许多余全透明边。逐层暂存支持复用已合格结果，正式完整回传才创建结果节点。拒绝不符产物时保留原结果，不静默反复生图。总图改尺寸须同步相关坐标，局部修改不能擅改整图尺寸。
- **R14 模型设置**：粗抠与两款精抠分别提供现有参数、通用默认值、用途及增减影响提示；保存后成为默认。下载优先可信国内源，完整性失败回退官方。不伪装缺失的模型为可用。

## 标注与意见

- **R15 坐标标注**：箭头、圈选、框选、涂抹和文字使用图片局部像素坐标。允许箭尾和文字在图片外；给 Codex 传坐标、对象归属和意见，不能把标注烧进原图让生图模型猜位置。选择蒙版和抠图预览蒙版用途不同。
- **R16 可见性和样式**：平时不显示标注；单选图片显示该图片标注，选图层高亮所属标注；框选中或多选时隐藏标注。五种工具均保留颜色和粗细设置，涂抹另有透明度。
- **R17 意见作用域**：未选图层时显示总图意见，不混入每层意见；选层才显示该层意见。提示词框下方用可换行的横向小标签展示当前作用域的标注，点击定位/编辑，悬停显示删除叉。不能把总图要求误当成所有图层各自的要求。

## 矢量化与导出

- **R18 入口**：矢量化按钮读取当前节点状态。原位图可直接转换；已分层结果逐层转换并保留层级。禁止混合位图冒充纯矢量，不通过 GPT 手绘替代所选转换引擎。
- **R19 服务选择**：设置保留四个独立入口，并显示来源、特点、费用和凭证说明；API 密钥由使用者自行配置。价格以服务商当时公布为准，费用提示不是效果保证。

| 入口 | 保留的使用方式与说明 |
|---|---|
| Vectorizer.com | 免费网页转换；自动脚本与当前 Codex 操作网页两种方式；遇验证明确等待用户完成，不绕过验证。成功下载后自动回传 |
| Recraft 官方 API | 按量收费，优秀效果选项，链接官方凭证/费用页面 |
| 302.AI Vectorizer 接口 | 国内按量转接，独立密钥；提供 302 产品地址及 Vectorizer.AI 官网来源 |
| Vectorizer.AI 官方 API | 官网订阅入口单列，最佳效果推荐标签属于产品选择提示；不与国内转接混为一个凭证 |

- **R20 导出**：保留 PSD、SVG 和当前支持的导出选项。可可靠重建的文字和描边/阴影尽量保留原生可编辑属性；特殊变形字、缺失字体、无法可靠还原的效果可独立栅格层并说明。纯矢量不能内嵌位图。AI 文件必须由真实 Illustrator 格式产出，不能将 SVG 改扩展名冒充。

## Codex 任务与 Adobe 兜底

- **R21 自动交接**：从插件点击需要 Codex 的操作，应通过官方 App Tools 发到打开画布的同一对话；无需用户再手打“执行”。任务区显示真实发送/接收/执行/失败/验证等待状态；宿主能力不支持时如实报错，不能假装接单或用私人数据库协议补洞。
- **R22 可靠回传**：绑定 taskId/jobId/imageId/baseVersion；冻结输入，正确处理取消、版本冲突、重复回传、旧版本分支。成功须有真实文件、格式/尺寸/图层检查、新节点保存和画布可见，排队或占位不算完成。
- **R23 Adobe**：PS/AI 仅作最终兜底，可选 MCP/Windows 脚本；基本功能不依赖安装 Adobe。只保留交接按钮，悬停提示“非常消耗额度”。分通道显示成功/失败和部分成功原因，代码放详情。任务携带当前意见、标注、正确层/重建层、干净参考及一致性原则。操作新文档或副本，结果可重新导入；连接不等于真实编辑成功。
- **R24 安装和隐私**：适配不同 Windows 用户、中文/空格/长路径以及不同 Codex/Adobe 安装目录；源码不含本机 MCP 路径、密钥、用户素材和模型大文件。安装结果分组件报告。账号/付费操作不能静默代办。

## 维护与本次整理的边界

- **R25 不变性**：本次优化不得更改以上交互、现有设置含义和有效工作流。删除仅限经引用检查确定退役的代码、专用运行时和权重；保留 U2NetP、BiRefNet、Lucida、共享 Python 环境及 Adobe 连接代码。
- **R26 验证**：运行类型检查、构建、相关测试及完整回归；最后进行一次无会话历史的只读冷审核，记录发现、修复和未覆盖范围。模拟测试不能宣称真实收费 API、Adobe 或生图已经成功。

已撤销：旧方案1（粗抠→精抠后保留可见像素）、SuperSVG/AdaVec 本地矢量入口、预览像素保真重建要求。兼容旧数据所需的字段迁移和明确报错入口可保留。模型质量、任意字体完整恢复、外部网站稳定性和工具未开放的尺寸/质量参数不作无条件保证。
