# 当前需求与验收边界

本文件描述2026-09-19公开版本，替代早期三方案/本地矢量模型设计。

1. 仅 Windows，运行在当前 Codex 对话；一个对话一个独立多图画布，无独立聊天侧栏。
2. 原图导入后不自动分层；预分层是透明预览及意见调整阶段，确认后才正式重建与补全。
3. 仅 PSD 方案2和3；PSD 流程不接独立商业生图 API，使用当前 Codex 可用生成工具。
4. 矢量化可读原图或已完成分层的当前节点；免费网页、Recraft、Vectorizer.AI 官方和302转接可选。无 SuperSVG/AdaVec 产品入口。
5. 一个请求只处理当前节点；新结果产生来源关联节点，不联动重做上下游。原图仅辅助参考，不能覆盖已确认修改。
6. 标注是图像像素坐标与意见，允许文字/箭尾超出图片；移动节点同步移动标注。不选图、框选或多选时不显示标注。
7. 总图意见独立；选择图层才展示该层意见。标签可选中、编辑、删除，支持样式设置。
8. 紧凑统一图标、9px关联线、原图对比开关、明暗主题、可拖动面板与输入框。
9. PS/AI 为最终兜底，不是基础依赖。按钮悬停提示高额度；连接按通道显示真实成功/失败，详细技术信息折叠。
10. 透明抠图、可编辑文字、纯矢量和真实AI格式都需实际文件验证；不能保证未知字体、所有原生效果和任意图片完美恢复。
11. 项目保留用户数据、任务版本、历史结果与撤销能力；不把任务排队或节点占位视为完成。
