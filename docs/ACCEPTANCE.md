# 验收说明与限制

本次发布检查源码可安装、构建和测试，不把开发者电脑成功等同于所有机器成功。

- 类型检查、生产构建和完整 npm test 的最终结果见发布记录；测试使用临时素材/数据及模拟外部服务。
- 当前实际画布已验证：多图/分层结果显示、矢量输出回传、原图开关来回切换、7层矢量结果保留。个人素材不随发布附带。
- 自动对话发送依赖宿主官方工具与环境，需在每台机器验证；测试发送回执不代表实际生图完成。
- 本次公开打包不重新触发付费API、不重建用户图片，也不声称完成全新电脑/干净Windows安装验收。
- Adobe握手、只读脚本通道与真实复杂编辑分别验收；特定版本曾成功不代表任意2026版本都兼容。
- 无通用质量保证：复杂艺术字、变形、透明边缘、混合效果和纯矢量细节须按素材检查。
- 免费网站可用性/验证码、模型下载源和第三方API价格可能变化；不保证无人值守。
- JSON只导出结构，完整备份要保留data；删除节点不清除底层素材。

公开代码未经过独立全面安全审计。报告问题时提供无隐私复现步骤，不上传私人数据或令牌。
