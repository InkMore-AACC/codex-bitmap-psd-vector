# 设计师使用教程

## 打开与导入

在 Codex 中说“打开分层画布”。每个对话使用自己的画布，切换对话不会自动带走图片。点击“导入”选择多张 PNG、JPEG、WebP、PSD 或 SVG；也可以拖入文件，或请 Codex 导入当前对话生成工具返回的图片原文件。

一张图片是一个节点。选择工具下拖动图片移动位置，空格拖动画布；图片移动会带着自身标注移动。空白处拖出选框可选多张图片，Shift / Ctrl 点击也可多选。Delete 或顶部删除按钮删除选中节点，可撤销；其他节点保留，素材文件暂不清理。编辑文字时 Delete 按文字编辑行为处理。

未选图片、框选中或多选时不显示标注。只选一张时显示该图标注。

## 把位图变成分层 PSD

1. 选中要处理的图片，在 PSD 设置中选方案2或3。
2. 点击“预分层”，Codex 规划图层并回传透明预览。此时仅供检查，不是完整的最终 PSD。
3. 查看图层名称、顺序与归属，拖动图层排序，标记“保留”或“重建”，写修改意见。
4. 确认分层后，Codex 重建图层并补全被遮挡内容；最终创建一个与当前节点关联的新节点。
5. 选中新结果检查各层，再导出 PSD。需要继续修改时在该结果上标注并提交，会生成下一版节点。

| 方案 | 预览由谁完成 | 最终分层 | 适用选择 |
|---|---|---|---|
| 2 | Codex 规划 + 本地粗抠 | Codex 生成重建 | 先尝试本地快速预览；本地抠图本身不耗额度 |
| 3 | Codex 生成预览 | Codex 生成重建 | 本地粗抠不适合当前素材时尝试；预览也耗额度 |

两种方案都不是从扁平图片恢复原始 PSD 的保证。文字尽量重建成可编辑文字及支持的原生字效；未知字体或复杂艺术字可能保留独立像素层。必须检查实际文件，不能只看合成预览判断文字可编辑。

## 写意见与标注

- 选择总图：输入整张图片的要求，例如“放大到2K，保持图层结构”。不会把每层的意见混在这个框里。
- 点击一个图层：显示该层意见，并突出其标注；例如“主体放大一点，保持人物外观”。
- 箭头、圈选、框选、涂抹、文字都有颜色与粗细设置；文字有字号/字重，涂抹另有透明度。
- 箭头末端指向目标，箭尾和文字可以拖到图片外。标注保存为图片局部像素坐标、意见和独立选区；不是把带箭头的截图当作新原图。
- 输入框下方的标注小标签可横向换行。点击标签选中标注并修改意见；鼠标悬停时右上角“×”可删除。
- 右侧图层栏、意见栏及意见输入区都能拖动边缘调大小。

选择单个图层提交修改/矢量化时，请检查任务作用范围；整图操作前先点“总图”。关联连线只表示来源，不会把整条来源链都重新执行。

## 原图参考与版本

当前节点及已经确认的修改是基准，最初上传的原图是只读辅助参考。例如你把衣服改成红色后再次修改文字，插件不会因为原图是蓝衣服就要求改回蓝色。

左下“显示原图”仅切换选中节点的对比预览，关闭后返回当前结果。不改变所选图层、任务输入或导出内容；对比时隐藏标注，需关掉开关后在结果上标注。来源链不完整时开关不可用。根节点没有上游时，对比的是它自己导入时的干净素材。

## 矢量化

可直接选原图转换，也可先完成分层再按层转换。预分层须先确认生成最终层，或改选原始节点直接转换。点击“矢量化”只处理当前节点，完成后创建新结果节点。

| 入口 | 需要配置 | 费用说明 |
|---|---|---|
| Vectorizer.com 自动脚本 | 本机浏览器 | 网站免费；脚本本身不耗 Codex 额度 |
| Vectorizer.com Codex 操作网页 | 可用的 Codex 浏览器控制 | 网站免费，操作过程耗 Codex 额度 |
| Recraft 官方 API | 自己的 API Key | 按服务商每次/每张请求收费 |
| Vectorizer.AI 官方 API | API ID、Secret 和 API 套餐 | 按月套餐额度；网页会员与 API 不等同 |
| Vectorizer.AI · 302.AI | 302 API Key | 302 转接、按次扣费，非原厂直连 |

“效果最好/优秀”等文字是产品推荐标记，不是每张图都保证的评测结论。图层越多，可能调用次数和费用越多；设置内价格文字为开发时参考，实际以服务商结算为准。免费网页可能要求人工验证，不能保证无人值守完成。

## 导出与 Adobe 交接

- **PSD**：用于 Photoshop 等支持 PSD 的软件。不是所有原生高级特性都能无损往返。
- **SVG**：纯矢量输出，不允许内嵌位图伪装矢量；图层用分组表达，不同编辑器可能显示不同。
- **PNG**：当前结果的合成图；“显示原图”开关不改变导出内容。
- **项目 JSON**：结构记录，不包含完整素材；完整备份需保留 `data/`。
- **交接 PS / AI**：最后兜底。交给当前 Codex 在已安装软件里处理，并核验产物再导回。悬停显示高额度提醒。原生 AI 只有实际保存后才可下载，不能由改扩展名得到。

## 任务状态

“正在发送/已发送”说明请求传输状态；“执行中”说明正在处理；“已完成”必须对应实际输出回传。对话正在忙时可能排队。取消不会抹掉原有节点，已发出的付费请求可能仍产生费用。失败时先看短原因，再展开详情；不要反复点击制造重复收费。
