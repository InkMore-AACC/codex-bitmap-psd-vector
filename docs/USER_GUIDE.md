# 设计师使用教程

## 打开与导入

在 Codex 中说“打开分层画布”。每个对话使用自己的画布，切换对话不会自动带走图片。点击“导入”选择多张 PNG、JPEG、WebP、PSD 或 SVG；也可以拖入文件，或请 Codex 导入当前对话生成工具返回的图片原文件。

一张图片是一个节点。选择工具下拖动图片移动位置，空格拖动画布；图片移动会带着自身标注移动。空白处拖出选框可选多张图片，Shift / Ctrl 点击也可多选。Delete 或顶部删除按钮删除选中节点，可撤销；其他节点保留，素材文件暂不清理。编辑文字时 Delete 按文字编辑行为处理。

未选图片、框选中或多选时不显示标注。只选一张时显示该图标注。

## 把位图变成分层 PSD

1. 选中要处理的图片，在 PSD 设置中选择一种流程。
2. 点击“预分层”，Codex 规划图层。方案3只显示干净原图和带名称的虚线框，不抠图、不生成图片；其他方案运行对应本地模型提供透明预览。此时仅供检查，不是完整的最终 PSD。
3. 查看图层名称、顺序与归属，拖动图层排序，标记“保留”或“重建”，写修改意见。
4. 确认分层后，Codex 重建图层并补全被遮挡内容；最终创建一个与当前节点关联的新节点。
5. 选中新结果检查各层，再导出 PSD。需要继续修改时在该结果上标注并提交，会生成下一版节点。

| 方案 | 预览由谁完成 | 最终分层 | 适用选择 |
|---|---|---|---|
| 2 | Codex 规划 + 本地粗抠 | Codex 生成重建 | 先尝试本地快速预览；本地抠图本身不耗额度 |
| 3 | Codex 理解图片、规划图层框 | Codex 生成重建 | 预分层仅消耗理解和规划额度；确认后才生图 |
| 4 | BiRefNet HR-matting 直接从原图精细抠图 | 精细预览辅助分层与标注，Codex 对照原图重建各层 | 通用默认；本地抠图不耗额度 |
| 5 | Lucida v7 直接从原图精细抠图 | 精细预览辅助分层与标注，Codex 对照原图重建各层 | 可与 BiRefNet 对照；本地抠图不耗额度 |

这些流程都不是从扁平图片恢复原始 PSD 的保证。文字尽量重建成可编辑文字及支持的原生字效；未知字体或复杂艺术字可能保留独立像素层。必须检查实际文件，不能只看合成预览判断文字可编辑。

## 写意见与标注

- 选择总图：输入整张图片的要求，例如“放大到2K，保持图层结构”。不会把每层的意见混在这个框里。
- 点击一个图层：显示该层意见，并突出其标注；例如“主体放大一点，保持人物外观”。
- 箭头、圈选、框选、涂抹、文字都有颜色与粗细设置；文字有字号/字重，涂抹另有透明度。
- 箭头末端指向目标，箭尾和文字可以拖到图片外。标注保存为图片局部像素坐标、意见和独立选区；不是把带箭头的截图当作新原图。
- 输入框下方的标注小标签可横向换行。点击标签选中标注并修改意见；鼠标悬停时右上角“×”可删除。
- 右侧图层栏、意见栏及意见输入区都能拖动边缘调大小。

选择单个图层提交修改/矢量化时，请检查任务作用范围；整图操作前先点“总图”。关联连线只表示来源，不会把整条来源链都重新执行。

## 原图参考与版本

当前节点及已经确认的修改是基准，最初上传的原图是只读辅助参考。例如你把衣服改成红色后再次修改文字，插件不会因为原图是蓝衣服就要求改回蓝色。

Codex 重建、补图和生成默认附带一致性原则：最初导入的原图用于核对未要求变化的主体、构图、材质、光照、配色、文字和透明细节；当前节点保留已确认的修改，本次明确要求只在对应范围内优先。补背景与遮挡区域按周边内容自然延续，不擅自重新设计。粗抠与精抠只有预览清晰度不同，均仅用于用户查看与标注；最终只把对象归属、坐标、顺序及意见交给 Codex，抠图图片与蒙版不作为生图参考或像素来源。PS/AI 交接沿用同一原则。无可用最初原图时会要求 Codex 说明参考限制；一致性仍需检查实际结果，不能只凭提示词保证。

左下“显示原图”仅切换选中节点的对比预览，关闭后返回当前结果。不改变所选图层、任务输入或导出内容；对比时隐藏标注，需关掉开关后在结果上标注。来源链不完整时开关不可用。根节点没有上游时，对比的是它自己导入时的干净素材。

## 矢量化

可直接选原图转换，也可先完成分层再按层转换。预分层须先确认生成最终层，或改选原始节点直接转换。点击“矢量化”只处理当前节点，完成后创建新结果节点。

| 入口 | 需要配置 | 费用说明 |
|---|---|---|
| Vectorizer.com 自动脚本 | 本机浏览器 | 网站免费；脚本本身不耗 Codex 额度 |
| Vectorizer.com Codex 操作网页 | 可用的 Codex 浏览器控制 | 网站免费，操作过程耗 Codex 额度 |
| Recraft 官方 API | 自己的 API Key | 按服务商每次/每张请求收费 |
| Vectorizer.AI 官方 API | API ID、Secret 和 API 套餐 | 按月套餐额度；网页会员与 API 不等同 |
| Vectorizer.AI · 302.AI | 302 API Key | 302 转接、按次扣费，非原厂直连 |

“效果最好/优秀”等文字是产品推荐标记，不是每张图都保证的评测结论。图层越多，可能调用次数和费用越多；设置内价格文字为开发时参考，实际以服务商结算为准。免费网页可能要求人工验证，不能保证无人值守完成。

## 导出与 Adobe 交接

- **PSD**：用于 Photoshop 等支持 PSD 的软件。不是所有原生高级特性都能无损往返。
- **SVG**：纯矢量输出，不允许内嵌位图伪装矢量；图层用分组表达，不同编辑器可能显示不同。
- **PNG**：当前结果的合成图；“显示原图”开关不改变导出内容。
- **项目 JSON**：结构记录，不包含完整素材；完整备份需保留 `data/`。
- **交接 PS / AI**：最后兜底。交给当前 Codex 在已安装软件里处理，并核验产物再导回。悬停显示高额度提醒。原生 AI 只有实际保存后才可下载，不能由改扩展名得到。

## 任务状态

“正在发送/已发送”说明请求传输状态；“执行中”说明正在处理；“已完成”必须对应实际输出回传。对话正在忙时可能排队。取消不会抹掉原有节点，已发出的付费请求可能仍产生费用。失败时先看短原因，再展开详情；不要反复点击制造重复收费。


## 抠图设置和通用默认值

在「设置 → PSD 分层」选流程，展开相应模型参数，点击「保存并设为默认」。参数用途及增减影响直接写在字段下方，鼠标停留也能看到。三个模型各自保存，不会互相覆盖。保存影响当前画布后续提交的任务，以及以后新建的对话画布；其他已有画布保留各自设置，排队任务使用提交时冻结的设置。

| 参数 | 通用默认值 | 作用和调整方向 |
|---|---|---|
| 处理分辨率 | BiRefNet 2048；Lucida v7 1024 | 增大通常有更多细节、耗时和显存增加；减小更快但可能丢细线。更大不保证更准，不改变导出尺寸 |
| 运行设备 | 自动，优先 NVIDIA CUDA | 显卡通常快；CPU 更通用但慢。指定不可用显卡会报错 |
| 计算精度 | FP32 | 稳定优先；FP16 在显卡上省显存，可能改变微弱透明度。CPU 使用 FP32 |
| 框外保留范围 | 精细 32px；粗抠 0px | 增大给发丝/光晕留空间但可能带入邻物；减小更聚焦但可能截断边缘 |
| 边缘柔化 | 0 | 增大变柔但可能糊发丝；0 保留模型原生软透明度 |
| 边缘扩缩 | 0 | 正数扩张，可能带背景；负数收缩，可能丢发丝/光晕 |
| 透明点 / 不透明点 | 0 / 1 | 提高透明点清灰但损失光晕；降低不透明点让主体更实但损失透明感 |
| 去除边缘背景染色 | 关闭 | 开启估算并去除背景串色，会改变 RGB；保留彩色光晕、玻璃时优先关闭 |
| U2NetP CPU 线程 | 8 | 增大可能加快，也占更多 CPU，过多不保证快；减小更省资源 |

恢复通用值后仍需点击保存。分辨率、设备和精度为精细模型参数；粗抠 U2NetP 输入固定 320×320。柔化、扩缩、透明点与去染色是插件的后处理，不是模型重新训练参数。对光晕优先保留 0/1 透明范围，别一开始就强行收边。

精细流程依然先显示预分层，确认后与粗抠一样，由 Codex 使用干净原图、当前输入和结构化图层意见重建。发丝等清晰细节只方便你查看预览，不作为生图输入；不会再次调用精细模型准备重建素材。确认分层不代表确认抠图像素质量。已确认正确的正式结果图层仍可保留。

## 调整预分层画幅

在预分层节点选中一个图层，切换左侧“选择”工具。拖动虚线框的边或角改变该层的重建范围，拖动框上尺寸标签移动整个框；右侧“恢复建议画幅”恢复初始范围。支持撤销、重做和自动保存，刷新后仍保留。框外允许留白，但应为发丝、阴影、光晕及遮挡补全预留足够空间。框的调整不缩放图片、不移动标注，也不运行模型。多选、总图和原图对比时不显示可调整框。

正式分层时，任务冻结你确认的位置、宽高和意见。每层按自己的画幅提出生成要求，结果在同一位置放回。合并图层使用来源框的并集。背景默认整张图片；粗抠、精抠只影响预览，不作为重建像素参考。

### 手动增加预分层

预分层阶段点击图层栏标题旁的 **＋** 新建图层。新层只有规划框，不会抠图、生图或消耗生图额度。选中它后在意见栏填写图层名称（例如“右上角花朵与光晕”），拖动虚线框的边缘/角点改变大小，拖动框上方的尺寸标签移动范围；再填写此层的修改意见或添加标注。框内有多个对象时，用名称、意见和标注明确哪些对象属于此层。

规划层显示编号占位图，不以截图伪装成抠图缩略图。选中图片时能查看它的规划框，点击框的名称可选中对应层；眼睛按钮控制该层框是否显示，不会从原图中删除物体。可调整图层顺序，点击标题旁的 **−** 删除选中预分层及其标注，误删可撤销。新建、改名、画幅和意见都会自动保存，重开仍保留。

这些操作适用于全部预分层方案，本地抠图预览也能追加规划层。确认分层后才按最终列表重建，产生关联的新结果节点。未完成的规划框不能导出为正式 PSD 或直接矢量化；删空图层时须先新增至少一层。历史已有的抠图或生成预览保持原样，不自动删除或重做。

生图尺寸不能靠提示词硬性保证。选中预分层图层时会显示预计生成宽高；画幅超过155万像素会出现小字提醒，仍可继续。插件按比例算出预算内的请求尺寸，保留你设置的最终框。实际返回可能更大（例如约157万像素）或更小，插件会重新计算倍率，等比放大或缩小，放回原位置；放大会影响清晰度。

宽高比偏差不超过1%时自动适配，绝不分别拉伸宽高；前景补少量透明边，背景复制边缘像素补微小缝隙，并提示检查接缝。超过1%会保留产物并报告问题，不自动反复生图。仅明确确认的多余全透明边可裁切，发丝、光晕等非零透明度内容不得裁掉。结果区显示实际生成尺寸、最终尺寸和适配倍率。

Codex 可先逐层暂存、检查，再正式提交结果节点。一层有问题不需要重生成其他已合格图层。暂存不是完成，最终仍需要检查全部图层合成的一致性。尺寸检查无法判断物体是否被模型画偏。
